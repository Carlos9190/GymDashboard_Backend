# GymDashboard Backend

## Description
This is the backend for the **GymDashboard** project which provides a RESTful API.

---

## Technologies Used

- **MongoDB & Mongoose** - NoSQL database and ODM
- **JSON Web Tokens (JWT)** - Secure authentication
- **Express.js** - Framework for building REST APIs
- **Node.js** - JavaScript runtime environment
- **TypeScript** - Static typing for JavaScript
- **Nodemailer** - Email sending service
- **Bcrypt** - Password encryption

---

## Installation

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Carlos9190/GymDashboard_Backend.git
cd GymDashboard_Backend
```

### 2️⃣ Install dependencies
```bash
npm install
```

### 3️⃣ Configure environment variables
Create a `.env` file in the project's root directory and check the `.env.example` file.

---

## Usage

### Start the Server

For Postman testing in local development:
```bash
npm run dev:api
```
For deployment or full application usage:
```bash
npm run dev
```

---

### Endpoints

For complete documentation, check the **Postman** JSON collection at the `collections` folder in the project's root directory.
